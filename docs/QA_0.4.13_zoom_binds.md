# Orbit 0.4.13 — Zoom, бинды и жирный HUD

Minecraft 1.21.11 / Fabric. Сборка — JDK 25, Gradle 9.8.2, Loom 1.19.3; байткод Java 21.

## Что изменилось

- General: Zoom, исходно включён; удержание C, оптическое приближение 3×, колесо 1.25–30×, плавный возврат и пропорциональная чувствительность. FOV и чувствительность в Options не перезаписываются. У предметов в руках остаётся штатный FOV.
- Сила зума сохраняется между обычными отпусканиями клавиши, но сбрасывается к 3× при выходе из игрового контекста. На диск сохраняются флаг Zoom и бинды, не величина приближения.
- У каждой из 11 существующих функций есть «Бинд» в окне по ПКМ. Назначение, явное отсутствие бинда, возврат к управлению Minecraft и отмена — отдельные действия. Изменение применяется только кнопкой «Сохранить».
- FreeLook и Zoom — удержание. ElytraSwap — один обмен по нажатию при включённом модуле. Остальные функции — переключение флага. Повторы GLFW_REPEAT не переключают их заново.
- Профильные переопределения сохраняются вместе с остальными настройками и включены в именованные конфиги. Старые файлы совместимы; повреждённый файл не перезаписывается.
- Клавиша открытия меню зарезервирована. Общий бинд нескольких функций показывает предупреждение; действия Minecraft на той же клавише не блокируются.
- Плашка ORBIT / FPS / пинг использует существующий Orbit UI Bold, реальный вес 700. Измерение и отрисовка используют один и тот же стилизованный Component; остальные плашки не стали жирными.

## Автоматические проверки

- `gradle --offline --no-daemon build` — PASS.
- Все 12 `scripts/test-*.sh` — PASS. Новый `test-zoom-binds.sh`: 1 894 проверки, включая строгие коды клавиш/мыши, неизменяемость, отсутствие бинда и возврат к умолчанию, сохранение по двум отдельным файлам, совместимость старых настроек, именованные конфиги, защиту повреждённого файла, одноразовое действие и повторное взведение удержания.
- Математика Zoom проверена при 15/30/60/120/240/360 шагах в секунду, на ограничениях колёсика и некорректных числах. Отпускание возвращает точный исходный FOV.
- `test_glass.py`, `test_menu_assets.py`, `test_ui_coverage.py`, `verify_jar.py` — PASS.
- В итоговом JAR — 181 класс Java 21 и 40 клиентских миксинов, включая новый ZoomFovMixin. Тестового мода и локальных файлов аккаунтов в поставке нет.
- 23 исходных UI-ресурса и 18 описаний шрифтов сохранены. Переводы клавиши Zoom добавлены без изменения прежних переводов; шрифтовые TTF не перегенерированы.
- 67 классов аккаунтов, профилей, наведения, правил предметных модулей, рендера и состояния FreeLook побайтно совпадают с 0.4.12. В InventoryModules изменён источник одноразового запроса ElytraSwap, не алгоритм обмена предметов.
- CI-конфигурация обновлена для новых тестов и имени JAR. Удалённый GitHub Actions не запускался; публикации и push не выполнялись.

## Игровые проверки

Локальный dev-запуск Fabric текущих скомпилированных классов в собственном Xvfb с программным OpenGL. Remapped JAR отдельно прошёл проверку состава. Обычное окно — 1280×800, GUI scale 2; малое — 960×720, реальный GUI 320×240, scale 3.

- Реальный C: рост приближения от 1 до 3, колесо до 4.32×, отпускание обратно к 1. Тестовая мишень на снимках стала ровно в три раза шире. FOV в Options всё время 70.
- Колесо во время удержания не меняет слот; после отпускания снова меняет его.
- Удержание через паузу и настоящий перенос X11-фокуса не возобновляет Zoom автоматически. Отключение и повторное включение функции при зажатой клавише также требует отпускания.
- Реальный ПКМ по Zoom → «Бинд»: сохранение V, старый C перестаёт приближать. Проверены отмена черновика, Esc, запрет RShift, «Без бинда» и возврат C по умолчанию.
- NoFall: K включает один раз при удержании и выключает следующим нажатием. В меню и при вводе `kkkk` в чат состояние не меняется, текст сохраняется.
- Trajectories: назначена и проверена боковая Mouse 4.
- FreeLook: назначено удержание H в третьем лице; прежний LAlt больше не активирует обзор.
- ElytraSwap: назначен J; обмен нагрудника/элитр один раз за нажатие, без повторного обмена от удержания. Прежний G, меню и выключенный модуль не вызывают обмен.
- В малом окне кнопка бинда доступна у всех 11 функций. Проверены General, обе страницы KillAura, диалог назначения и жирная плашка HUD без наложений.
- На окончательных классах отдельно проверены кликабельная «Отмена» во время захвата, «Без бинда», «По умолчанию», игнорирование неактивной «Сохранить», назначение левой кнопки мыши и зарезервированный RShift. Это защищает от случайного назначения Mouse 1 при попытке отмены/сохранения.
- После полного перезапуска восстановлены H/K/J/Mouse 4, стандартный C, все флаги модулей и FOV 70. Повторно проверены рабочие C/K/Mouse 4 и отмена захвата на scale 3.
- Снимки обычного и малого интерфейса просмотрены по отдельности: жирный шрифт читаемый, текст и кнопки внутри панелей, переключатели и последняя страница доступны.

## Изоляция и ограничения

- Первый пробный запуск Loom проигнорировал переопределение workingDir. Он остановлен; 20 изменившихся файлов прежнего тестового run восстановлены из сохранённых копий с точным совпадением SHA-256. Дальнейшие проверки использовали отдельный runDir, а исходная папка была перенесена за пределы пути запуска. В конце возвращена исходная папка: совпали все 38 исходных контрольных сумм. Собственный Xvfb закрыт.
- Программный OpenGL не даёт репрезентативного FPS: это функциональная проверка, не тест производительности.
- Windows, реальный scale 4, нестандартные scancode-only устройства и сочетания со сторонними модами камеры/клавиш не проверялись. Бинды — одиночные клавиши/кнопки, не комбинации модификаторов.
- Реальный вход Ely.by/Microsoft и смена аккаунтов заново не выполнялись. Их классы не менялись; автоматические проверки используют синтетические данные. Новые поля именованных конфигов и изоляция сохранённых настроек проверены чтением/записью.
- В mods оставлять только один Orbit JAR. ZIP исходников туда не класть. Этап 3 не начат.
