# QA — Orbit 0.4.8, PvP stage 1, hotfix 1

## Причина и исправление

В исходной сборке `0.4.8-pvp-stage1` воспроизведён вылет `IllegalStateException: Can only blur once per frame`: одиночный мир, размытие меню 5, RShift → Pvp → ПКМ по KillAura.

Minecraft вызывает `Screen.renderBackground` перед `Screen.render`. Общий `MenuBackdropMixin` уже рисовал фон с размытием, но `ModuleSettingsScreen.render` запрашивал его повторно. Убран только второй вызов; штатная настройка размытия продолжает работать.

В `tools/verify_jar.py` добавлена проверка ссылок на методы в упакованном class-файле окна настроек. На прежнем JAR она обнаруживает повторный фон и завершается с ошибкой; на hotfix 1 проходит. Это целевая регрессионная проверка, не доказательство отсутствия любых ошибок рендера.

## Игровой прогон

Minecraft 1.21.11 / Fabric, Linux, JDK 25, окно 1280×800, GUI scale 2, llvmpipe. Два отдельных запуска исправленного клиента, оба с загрузкой одиночного тестового мира.

| Сценарий | Результат |
| --- | --- |
| KillAura: настройки по ПКМ из мира, размытие 5 | PASS: окно работает, мир за ним размыт |
| KillAura: изменение черновика → Esc → повторное открытие | PASS: приоритет остался CLOSEST |
| KillAura: вторая страница и сохранение | PASS |
| TriggerBot: кнопка `...`, сохранение, повторное открытие по ПКМ и отмена; размытие 5 | PASS |
| KillAura: настройки по ПКМ из мира, размытие 0 | PASS |
| TriggerBot: настройки по ПКМ из мира и сохранение, размытие 0 | PASS: фон мира остаётся чётким |
| Возврат из настроек, выход из мира и закрытие игры | PASS в обоих запусках; мир сохранён, штатное завершение |

В исправленных запусках нет `Can only blur once per frame`, `Game crashed!` или нового краш-отчёта. Оба новых модуля остались выключены. Окружение сохраняет прежние предупреждения офлайн-сессии Realms/недоступного narrator; это не исключения Orbit.

## Границы проверки

Это исправление конкретного вылета окна настроек. Отдельный повтор игрового теста нанесения урона не проводился; боевой код не менялся, исходные результаты находятся в `QA_0.4.8.md`. Windows, набор сторонних модов пользователя, публичные серверы и античиты не проверялись. GUI scale 4 в этом hotfix отдельно в игре не проверялся. FPS программного рендера не является замером производительности на видеокарте.

JAR: `orbit-0.4.8-pvp-stage1-hotfix1.jar`. Прежний JAR нужно убрать из `mods`, конфиги удалять не требуется. Публикации на GitHub не было.
