# Проверка Orbit 0.4.10 — аккаунты

## Комплект и границы проверки

Minecraft **1.21.11**, Fabric Loader **0.20.1**, Fabric API **0.141.6+1.21.11**. Сборка Gradle 9.8.2 на Java 25; классы мода рассчитаны на Java 21. Файл мода: `orbit-0.4.10-accounts.jar`. В `mods` должна оставаться одна версия Orbit; ZIP с исходниками — резервная копия, не мод.

Проверка проведена через Gradle `runClient` с собранными классами в настоящем клиенте Minecraft под Linux/Xvfb с программным OpenGL, а не в HTML-макете. Итоговый remapped JAR проверен отдельно по составу/байткоду; установка этого файла в пользовательский лаунчер не проверялась. Стенд не подходит для измерения игрового FPS и не заменяет проверку на Windows.

**Настоящие Ely.by/Microsoft-аккаунты, пароли и OAuth-токены не использовались. Полный онлайн-вход, подключение к Ely/лицензионному серверу, настоящий скин и подписанный онлайн-чат не подтверждены.** Microsoft Client ID в сборку не встроен: для начала входа требуется своё одобренное приложение. Ссылки регистрации ведут на официальные сайты; создание аккаунта в браузере не проверялось.

## Автоматические проверки — пройдены

Все команды запущены последовательно с остановкой при первой ошибке.

- Gradle `build`: успешные компиляция, обработка миксинов и remap.
- `scripts/test-accounts.sh`: **29 923 проверки** на поддельных ответах транспорта. Ely authenticate/2FA/refresh/invalidate, собственный client token; Microsoft device code, pending/slow_down, отмена/истечение/отказ, цепочка MSA → Xbox Live → XSTS → Minecraft, entitlement/profile, ограничения семейного аккаунта и приложения, безопасные ошибки, хранение публичного Client ID, геометрия форм и запрет переключения в неподходящем состоянии.
- `scripts/test-account-skins.sh`: **119 проверок**, только синтетические данные. Настоящая проверка RSA-подписи тестовым ключом; штатный закреплённый Ely-ключ отвергает чужую подпись. Неподписанные/испорченные текстуры, `Cg==`, опасные URL и слишком большие ответы отклоняются; известные HTTP URL текстур повышаются до HTTPS. Проверены отдельные Ely join/profile/name endpoints, соответствие UUID, ошибки сети/сессии и не-JSON ответы HTTP 429/5xx. Ошибочные подписи не печатают stack trace.
- Прежние тесты сохранены: ClickGUI **56**, combat/config/layout **72 477**, FreeLook **41**, контейнеры/пауза/профили **7 889**, modules/settings **132**, support/config/slots/ownership **3 326**, ProfileStore — успешно.
- `tools/test_glass.py`, `test_menu_assets.py`, `test_ui_coverage.py`: прежние UI-ресурсы, шрифты, логотип, 42 случая меню, 48 сопоставлений референсов, штатная геометрия слотов и сохранение item-tooltip.
- `tools/verify_jar.py`: **167 классов Java 21, 38 миксинов, 18 описаний шрифтов**, 23 побайтно сохранённых UI-ресурса 0.4.7 и два добавленных перевода клавиши G. Проверены отсутствие повторного вызова фона в новых формах, SHA-256 Ely public key и отсутствие локальных файлов аккаунтов в JAR.
- Дополнительное сравнение с JAR 0.4.9: **61 класс** старой combat/support/modules/config/render/FreeLook/HUD-логики сохранён побайтно.

Сценарии протоколов не обращаются в интернет и не доказывают доступность/совместимость реальных сервисов.

## Настоящий Minecraft — проверено

Для наблюдения внутреннего состояния использован отдельный временный QA-мод. Он не входит в Orbit JAR или ZIP исходников. В диагностике записывались публичные ник/UUID, флаги и совпадение объектов, не токены. Исходный мир защищён отдельно, вход выполнялся только в его одноразовую копию.

1. Через настоящие кнопки Profiles добавлены и применены `OrbitQA_A` и `OrbitQA_B`. Имя и детерминированный offline UUID изменились без перезапуска процесса.
2. После каждого переключения обновились профиль, skin/social/telemetry/reporting managers. Для offline-сессии активны offline User API и пустой менеджер ключей чата; Realms не разрешён, Realms session ID пуст, проверка доступности возвращает ошибку авторизации без подстановки Microsoft-сессии.
3. Выбор первой строки Launcher восстановил **тот же исходный объект User и те же исходные Services**, а не только исходную надпись ника.
4. С `OrbitQA_A` выполнен вход в копию локального мира. На встроенном сервере проверены настоящее имя игрока и UUID: совпали с текущей клиентской сессией.
5. Попытка смены личности в загруженном мире отклонена: User и revision не изменились.
6. После сохранения/выхода профиль переключён на `OrbitQA_B`. Повторный вход в тот же тестовый мир подтвердил новый ник и UUID на встроенном сервере, без перезапуска Minecraft.
7. Выполнены ещё **25 переходов**: 24 различных offline-профиля и возврат к точной исходной сессии лаунчера.
8. Главное меню, Profiles, выбор провайдера и формы Ely/Microsoft открывались в масштабе GUI 2 и 4 при окне 1280×800. Поля, пояснения и нижние кнопки помещаются. RShift и меню паузы открываются после смены личности.
9. В поле Ely введена только фиктивная тестовая строка: на экране видны звёздочки. Локальная ошибка пустого логина очищает пароль и не меняет текущую сессию; запрос авторизации не отправляется.
10. Выполнен второй запуск финальных классов: сохранённый `OrbitQA_A` автоматически применился после обычной загрузки главного меню. Исходный аккаунт лаунчера при этом не потерялся; его точное восстановление проверено повторно.
11. В настоящем SecretEditBox проверены narration без пароля, запрет Ctrl/Super+C/X, очистка после `takeAndClear` и `erase`. Использовалась только фиктивная строка.
12. Без Client ID кнопка получения Microsoft-кода действительно неактивна; сетевой вход не запускался.
13. Заголовки загрузчика серверных ресурспаков проверены после offline/Launcher-переходов: ник и UUID соответствуют текущему User. UUID в штатном заголовке имеет формат без дефисов.
14. После завершения оба тестовых клиента и Xvfb закрыты. Временный QA-мод/копия мира убраны из `run/`. Исходные настройки, конфиги и мир восстановлены: **38 исходных файлов совпали по SHA-256**.

В среде отмечены ожидаемые предупреждения отсутствующей библиотеки narrator, ошибки Realms от фиктивного токена Fabric dev-launcher и единичное GLFW/X11 `Standard cursor shape unavailable` на программном дисплее. Клиент продолжил работу; это не выдаётся за успешную онлайн-авторизацию или доказательство отсутствия любых графических проблем на другом компьютере.

## Защитные решения

- Смена доступна только в главном меню: без мира, игрока, соединения, незавершённого подключения, встроенного сервера и overlay; фиксация выполняется на клиентском потоке.
- Онлайн-вход сначала готовит полную сессию, затем применяет её целиком. Закрытие формы отменяет ожидание и не даёт позднему ответу применить аккаунт.
- Microsoft использует явно заданное production-окружение authlib, а не унаследованный custom environment лаунчера. Это не гарантия совместимости с javaagent/mod, который сам переписывает сетевые запросы.
- Ely — отдельный session/skin provider. Ключи Mojang глобально не заменяются, Ely-токен не подставляется в Realms/службы Microsoft.
- Онлайн-токены и пароли не сохраняются модом. Offline-ники и публичный Client ID сохраняются. Состояние heap/crash dump, сторонние моды и физическое обнуление строк JVM не входят в эти гарантии.
- Это не отключение всех штатных кэшей Minecraft: для официального аккаунта используется обычный менеджер подписанных ключей чата, который может сохранять их в `profilekeys/`. Они не являются access/refresh-токенами; их кэширование не заявляется как RAM-only.

## Не проверено и что проверить у себя

- Реальный вход Ely.by с 2FA/без неё, обновление действительного токена, доступность и формат настоящего профиля/скина, подключение к Ely-совместимому серверу.
- Реальное Microsoft-приложение с одобрением Minecraft API, вход в браузере, Java entitlement/Game Pass, родительские ограничения, Realms и secure-chat на лицензированном сервере.
- Windows, конкретный лаунчер, взаимодействие с другими account-switcher/authlib-injector/skin-модами и открытие внешнего браузера. Если другой мод также меняет сессию или endpoints, сначала проверять отдельно.
- QuickPlay и автоматическое прямое подключение при запуске: автоприменение сохранённого offline-профиля рассчитано на обычный вход через главное меню.
- Полная повторная игровая проверка всех модулей 0.4.9: их прежние тесты выполнены, но новый выпуск посвящён аккаунтам, не всем игровым ситуациям.
- Работа на сторонних серверах/античитах и производительность.

На offline-серверах новый ник/UUID может означать отдельные инвентарь, прогресс и права. Offline-профиль не заменяет лицензию и не меняет официальное имя аккаунта Microsoft.
