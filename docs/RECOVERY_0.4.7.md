# Восстановление базы 0.4.7 перед PvP-этапом

Рабочая папка в начале этапа содержала снимок 0.4.5, хотя ранее был выдан JAR 0.4.7. Старый снимок сохранён в отдельной резервной копии; Git не сбрасывался, удалённый репозиторий не изменялся.

Восстановление выполнено из опубликованной базы 0.4.6 (`a728bba36b0b7a0636ec06700e7f6111ede99434`) и ранее выданного JAR 0.4.7. Его SHA-256: `3533e48465ebe2a73105b1fbaf1be3f75181654fbe351e9e13e22809eb78809a`.

34 Java-файла сохранены из исходников 0.4.6 после точного совпадения соответствующих class-файлов. 45 обновлённых/новых Java-файлов восстановлены из JAR через обратный remap и Vineflower 1.11.1. Исправлены артефакты декомпиляции: cast через Object в mixin, повторные имена локальных переменных и захват изменяемого параметра в lambda. Это восстановленные исходники, не утверждение о побайтовом совпадении с потерянным текстом оригиналов.

Ресурсы интерфейса взяты из исходного JAR 0.4.7. Контрольные суммы находятся в `tools/assets/orbit047-resource-hashes.json`. Старый генератор UI 0.4.6 не запускается автоматически: иначе он заменил бы актуальные шрифты/формы устаревшими ресурсами.

В новый этап не добавлены специальные обходы античита и другие пункты расширенного списка. Публикации на GitHub не было.
