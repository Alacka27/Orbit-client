# Orbit 0.4.6 — проверки и ограничения

## Автоматические проверки

- Чистая Gradle build/remap: Java 25 для Loom, bytecode Java 21.
- Существующие тесты FreeLook (41), ClickGUI (56), модулей/настроек (132), хранения offline-профилей, ресурсов меню.
- 7 889 проверок панелей контейнеров, паузы и списка профилей, включая GUI 320×180 и компактные размеры.
- PNG/CRC/nine-slice/Unicode cmap, regular/bold OFL providers и fallback, имена производных шрифтов Orbit UI без Reserved Font Names, полная проверка JAR и Mixin configuration.
- Исходный clouds.png сравнивается с 0.4.5; никаких новых учётных данных и изменений авторизации.

## Настоящий Minecraft

Локальная отдельная копия мира Orbit 046 UI QA, без сторонних модов. Первый прогон: главное меню, RShift, тема (сброс/живой предпросмотр/применение), Profiles, выбор мира, инвентарь, чат, пауза, сохранение/выход. Окна 1280×720 и 854×480, GUI scale 2.

Положительная проверка 2×2: выдано 8 oak_log, мышью помещены в крафт, Shift-клик результата. `/data get entity @s Inventory` подтвердил один стек `minecraft:oak_planks`, count 32, без оставшихся брёвен. Это реальный результат, а не только компиляция или макет.

Финальный игровой прогон:

- **3×3:** мышью разложены 3 доски и 2 палки; Shift-клик результата. В данных игрока — одна `minecraft:wooden_pickaxe`, без оставшихся ингредиентов.
- **Сундук:** правый клик разделил 7 алмазов на 3 и 4; это подтверждено двумя записями `Items` в разных слотах. Отдельный Shift-перенос дал игроку 7 алмазов и оставил сундук пустым.
- **Печь:** сырьё и топливо загружены мышью, а не только через заранее заполненный NBT. Появился железный слиток; при проверке оставались 4 raw_iron и 3 coal, рецепт записался в `RecipesUsed`. Видны штатные огонь и прогресс.
- **Торговля:** настоящий тестовый библиотекарь обменял 24 бумаги на 1 изумруд; результат подтверждён в инвентаре игрока. Иконки, цены и обработчики предложения — vanilla.
- **Визуально открыты:** наковальня, зачарование, зельеварка, кузнечный и картографический столы, камнерез, ткацкий станок, точило, маяк, воронка, раздатчик, шалкер, сборщик и большой сундук. Панели/слоты проверены при 854×480; у большого сундука сохранены 54 верхних слота. Это не проверка всех рецептов каждого блока.
- **Creative / достижения / пауза:** вкладки, предметы, подсказка, дерево достижений и обычные кнопки отображаются. У паузы сохранены штатные действия, добавлено Меню Orbit.
- **Tab / F1 / F3:** список с настоящим игроком и тестовым scoreboard показан справа сверху; F1 скрыл весь HUD, F3 скрыл дополнительные плашки Orbit, оставив штатный debug overlay.
- **Смерть / возрождение:** открыт настоящий экран смерти тестового игрока, кнопка возрождения вернула его в мир.

Скриншоты сделаны из Minecraft, не из HTML-макета. В прогоне не обнаружены краши или ошибки применения Mixin. В окружении есть отсутствующий `libflite` для диктора и недоступная форма X11-курсора; эти сообщения не используются как подтверждение игрового рендера или производительности.

После последней чистой сборки повторены вход в мир, обмен 24 бумаги на изумруд, смерть/возрождение и сохранение/выход. Проверены фиолетовая подложка предложения без потери иконок, акцент кнопки возрождения и компактный HUD: в 854×480 хотбар не увеличивается сверх доступного места, а XYZ перемещается под FPS и не закрывает сердца или обычные строки чата.

## Не покрыто

Не заявляется тест на каждом сервере, на каждом сочетании GUI scale/ресурспаков, со всеми сторонними модами или всех 48 экранов по отдельности. Тестовая среда использует software-rendering: её FPS не является игровым бенчмарком. Авторизация Microsoft/Ely.by и смена сессии на лету не добавлялись; offline-профиль по-прежнему применяется при перезапуске. Неизвестные/modded контейнеры намеренно не заменяются.
