### Короткий игровой прогон

Minecraft 1.21.11 / Fabric, одиночный тестовый мир, окно 1280×800, GUI scale 2, программный OpenGL llvmpipe. Использовались деревянный меч и кадавр без ИИ. Числа здоровья ниже прочитаны командой тестового мира, а не выведены из анимации попадания.

| Сценарий | HP до → после | Результат |
| --- | --- | --- |
| KillAura включена, но открыто меню | 20 → 20 | Атаки при открытом меню остановлены |
| KillAura: цель сбоку, меню закрыто | 20 → 4.7396555 | Наведение и урон подтверждены |
| TriggerBot: прицел отведён от цели | 100 → 100 | Атак нет |
| TriggerBot: прицел на цели | 100 → 92.128006 | Урон подтверждён |
| Оба модуля включены, между игроком и целью стена | 92.128006 → 92.128006 | Сквозь стену не атакуют |
| Оба модуля включены, стена убрана | 92.128006 → 84.25601 | Совместная работа без сбоя |

Отсутствие двух атак в одном тике проверено отдельно тестом общего планировщика; сами изменения HP этого не доказывают из-за периода неуязвимости моба.

В интерфейсе проверены выключенное начальное состояние модулей, открытие настроек по ПКМ без переключения модуля, переход между страницами KillAura, отмена изменения через Esc и сохранение выбора «Мобы» в профиль. После прогона оба модуля выключены, игра штатно закрыта с сохранением мира.

В журнале были предупреждения окружения о недоступном narrator/libflite, Realms для офлайн-тестовой сессии и форме X11-курсора. Исключений Orbit или аварийного завершения не обнаружено. Это не замер производительности: FPS программного рендера не характеризует работу на видеокарте пользователя.

## Короткий тест пользователем

1. Убрать старый Orbit JAR из `mods`, оставить только новый. Minecraft 1.21.11, Fabric Loader 0.20.1+ и Fabric API для этой версии.
2. RShift → Pvp. Оба новых модуля по умолчанию OFF. На малом масштабе панели есть страницы; NoFall/Jesus не удалены.
3. ПКМ по KillAura → «Цели: Мобы», остальные значения по умолчанию, «Сохранить». Взять меч, включить модуль в одиночном тестовом мире рядом с мобом. Проверить наведение, удары по кулдауну и остановку после OFF.
4. Поставить между собой и мобом непрозрачный блок: ударов через стену быть не должно. Открыть чат/меню: атаки должны остановиться.
5. Отключить KillAura, аналогично настроить TriggerBot на мобов. Держать прицел на мобе, затем отвести: удары должны начинаться/прекращаться соответственно.
6. Включить оба: они используют один бюджет атак, не две независимые серии. Режим CPS — частота попыток, а не гарантированное количество нанесений урона.
7. Поменять настройку и нажать Esc: она не должна примениться. Повторить с «Сохранить», перезапустить игру и проверить сохранение. Проверить экспорт/импорт именованного конфига.
8. Проверить GUI scale 2/3/4, страницы настроек, перетаскивание окна и возврат в ClickGUI.

## Ограничения

GUI scale 4 проверен на уровне разметки, не отдельным игровым прогоном. Перетаскивание нового окна, импорт/экспорт через интерфейс и восстановление после полного перезапуска не проходили отдельную ручную проверку; соответствующая логика проверялась доступными самостоятельными тестами.

Нет отдельного игрового теста на других игроках, всех сочетаниях нескольких целей, режиме CPS на legacy-сервере, произвольных публичных серверах/античитах или Windows. Гарантия отсутствия бана не даётся. Копья не поддерживаются; обычная дальность оружия не увеличена. Точные HP чужих игроков не предполагаются доступными. Остальные 24 пункта расширенного списка в этот этап не входят.
