# 0.4.11 — проверка интерфейса

## Автоматически

- Offline Gradle build: успешно. JAR: Java 21, 41 mixin.
- Все 10 `scripts/test-*.sh` и четыре Python-проверки проходят.
- Новые 7177 проверок: размер второй руки, симметричные отступы с обеих сторон, нижняя граница хотбара, запас для чата, дополнительные сердца и короткие подсказки.
- Логотип, облака и 18 описаний шрифтов сохранены. В игровых функциях и ядре авторизации нет изменений; упаковщик сверяет их class-файлы с JAR 0.4.10 побайтно.
- Новое окно подсказки входит в проверку отсутствия повторного размытия.

## В Minecraft

Minecraft 1.21.11, Fabric Loader 0.20.1, Linux, software OpenGL, окно 1280×800.

- Масштабы GUI 2 и 3: чат и строка ввода выше нижнего HUD, элементы не обрезаны.
- Реальный клик по перенесённому сообщению с `suggest_command` заполняет строку ввода.
- Проверены ввод, выделение текста клавиатурой, прокрутка сообщений и клик по автодополнению.
- Список команд и справка команды привязаны к новой строке, а не к старой нижней границе. При появлении дополнительных сердец строка и список перемещаются вместе.
- Карточки без описаний; ПКМ открывает короткую подсказку либо настройки. Проверено открытие настроек из мира с размытием без повторного blur.
- Вторая рука слева отделена от рамки хотбара, размер совпадает с обычной ячейкой. Правая сторона проверена расчётами геометрии; фактическую смену ведущей руки на сервере отдельно не проверяли.
