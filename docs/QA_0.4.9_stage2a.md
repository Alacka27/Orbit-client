# QA — Orbit 0.4.9, items stage 2.1

Тестовая версия `0.4.9-items-stage2a`. Это первая половина этапа 2: AutoTotem, AutoArmor, AutoConsume и ElytraSwap. AutoBlock, ShiftTab, SafeWalk и TargetStrafe в эту сборку не входят. GitHub-публикации не было.

## База и воспроизводимость

- Восстановлена точная база из ранее выданного полного `orbit-0.4.8-stage1-hotfix1-sources.zip`: SHA-256 `b9338215408804f1408621013904ed06618b55f1e4782e3b02d5792575509f38`. Все 152 исходных файла восстановлены из ZIP, не декомпилированы заново. Изменения этапа 2.1 накладывались поверх этой базы.
- Сборка: Java 25 для Loom 1.19.3, Gradle 9.8.2, Minecraft 1.21.11, Fabric Loader 0.20.1, Fabric API 0.141.6+1.21.11. Выпускаемый байткод — Java 21.
- `gradle --no-daemon --offline build`: PASS после загрузки зависимостей. Для игрового запуска отдельно догружены стандартные assets Minecraft; первоначальный offline-запуск без индекса ресурсов закономерно не состоялся.
- Полный ZIP исходников включает src/tests/scripts/tools/docs/.github и настройки Gradle, но не run/config, миры, .git, кэши и личные данные. Он предназначен для восстановления проекта и не устанавливается в mods.

## Реальная игровая проверка

Linux/Xvfb 1280×800, GUI scale 2, программный OpenGL, меню blur 5. Использован настоящий Minecraft через Loom `runClient` из тех же исходников. Результаты предметов/HP/голода проверялись командами встроенного сервера, а не только по анимации. Готовый remapped JAR отдельно проверен упаковщиком; установка в сторонний лаунчер здесь не выполнялась.

Для изоляции исцеления в тестовом мире временно отключалась естественная регенерация серверной командой. Это не функция клиента. Кадавр был специально создан без AI. Первую попытку SafeOnly при голоде 20 не считали достаточной; проверка повторена при голоде 0.

28 положительных серверных контрольных отметок проверены программно. Ошибок обработчика предметов, неподтверждённого клиентом обмена и `Can only blur once per frame` в ходе этих сценариев не было. Стандартные предупреждения среды о недоступном Linux narrator/libflite, Realms с dev-сессией и курсоре X11 не выдаются за ошибки Orbit или их отсутствие.

## Ограничения и что проверить на своём ПК

- Не проверялись Windows/сторонние модпаки, публичные серверы, высокий пинг, отмена сервером транзакций и античиты. Нативные клики не гарантируют разрешение сервером. FPS программного рендера — не бенчмарк клиента.
- Собственный основной инвентарь 0–35; никакой работы с чужими/открытыми сундуками. Автоматике нужен пустой курсор. AutoConsume берёт только хотбар, только обычные питьевые полезные зелья; не бросает splash/lingering и не расходует вредные зелья.
- SafeOnly — консервативная проверка доступных клиенту сущностей в радиусе, в том числе за стеной. Команда учитывается, список друзей не добавлялся. Это не гарантия отсутствия любых угроз.
- AutoArmor использует общую эвристику: очки брони ×1000 + твёрдость ×100 + обычная Защита ×750 (если включена), затем прочность при равенстве. Не учитывает все специфические зачарования/типы урона и не снимает надетые элитры.
- Защита снятия элитр во время настоящего полёта, здоровье/поглощение AutoTotem, remap клавиши G и ручной use на нестандартной мыши/сканкоде не проверялись интерактивно. Прерывание именно входящим уроном, потерей фокуса и сменой мира проверено логикой/ревью, не полноценным сетевым боем.
- Геометрия GUI scale 4 проверена чистыми тестами; живая проверка этой версии выполнялась на scale 2 и blur 5. Blur 0 в этом игровом прогоне отдельно не проверяли.
- Все четыре модуля OFF на чистом профиле/старом конфиге. Параметры модулей сохраняются только по «Сохранить»; ЛКМ по карточке отдельно меняет включение.
- Следующая часть 2.2 — AutoBlock, ShiftTab, SafeWalk, TargetStrafe — не заявляется готовой.

## Короткая проверка пользователя

1. Оставить в mods одну версию Orbit, добавить совместимый Fabric API. ZIP исходников туда не класть.
2. RShift → Pvp → `2/2 >`: включать по одному новому модулю, ПКМ открывает настройки.
3. Для AutoConsume положить еду в хотбар; зелья/яблоки при необходимости включить отдельно. Учесть SafeOnly.
4. Для ElytraSwap включить модуль и нажать G; конфликт клавиши можно переназначить в Управлении Minecraft.
5. Проверить своё размытие/масштаб GUI, переключение предметов, отмену едой/щитом, фокус и игру на нужном сервере, где мод разрешён.
