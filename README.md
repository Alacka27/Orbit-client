# Orbit client — Fabric 1.21.11

## 0.4.3-ui-fix — исправление квадратов и единая тема

- Исправлена реальная причина пропавшего текста: TTF provider ошибочно ссылался на `orbit:font/ui.ttf`, хотя Minecraft сам добавляет `font/`. Правильный путь — `orbit:ui.ttf`.
- Один шрифт применяется и к отрисовке, и к измерению текста: кнопки, заголовки, списки, поля ввода, подписи настроек. Если шрифт недоступен, остаётся стандартный читаемый шрифт Minecraft.
- Фон с облаками сохранён, акцент фиолетовый. Тема общая для меню, настроек и меню паузы; ползунки, скроллбары, чекбоксы, вкладки и диалоги оформлены вместе с кнопками и карточками. Убраны стандартные чёрные разделительные полосы вкладок создания мира.
- Подсказки в полях сделаны светлее, а бегунок ползунка перенесён ниже подписи, чтобы не перекрывать текст.
- Политика оформления для следующих изменений: [docs/UI_STYLE.md](docs/UI_STYLE.md).
- Добавлены регрессионные тесты фактического пути TTF и наличия русских/английских символов в таблице Unicode шрифта.
- На настоящем запуске Minecraft 1.21.11 проверены главное меню, Profiles, настройки/графические настройки, список серверов с локальными тестовыми записями и вкладки создания мира. Проверены окно 1280×720 и 854×480 при GUI scale 2. При удалённом UI-font definition и перезагрузке ресурсов отображается стандартный шрифт; после восстановления возвращается сглаженный. Это не тест всех сторонних модов, Microsoft/Ely.by, подключения к реальным серверам или FreeLook в мире.
- HUD, чат, инвентарь и контейнеры в этой версии не переделаны. Авторизация Microsoft/Ely.by и логика профилей этим исправлением не меняются.

## 0.4.2-violet-glass — мягкое оформление меню

- **Прежний фон с фиолетовыми облаками сохранён без изменения.** Фиолетовый акцент, тёмные полупрозрачные панели, мягкая рамка и сглаженные скругления — по присланным референсам, без красного акцента.
- Кнопки используют nine-slice текстуры со сглаживанием вместо сотен прямоугольных полос. Сохраняется плавная подсветка при наведении и фокусе с клавиатуры; `animation=false` отключает её.
- Для подписей кнопок и части заголовков добавлен Orbit UI — подмножество Liberation Sans с латиницей и кириллицей под SIL OFL (лицензия включена в JAR). Системный шрифт Minecraft в мире не заменяется; текст списка, курсор и редактирование остаются штатными.
- Главное меню: «Мультиплеер» — акцентная кнопка, «Одиночная игра» ниже, «Настройки» и «Выход» в одной строке. Profiles остаётся справа снизу.
- Выбор мира и список серверов: общая скруглённая панель и отдельные полупрозрачные карточки, с фиолетовым выделением выбранной строки. Поля ввода в меню до входа в мир получают мягкую рамку вместо чёрного прямоугольника. Иконки миров, серверов и содержимое строк остаются штатными.
- Profiles оформлен той же темой. Логика профилей, ограничение входа и применение выбора после перезапуска не изменены. Microsoft/Ely.by авторизация этим обновлением не добавляется.
- Это **не настоящий blur** и не изменение HUD/меню внутри загруженного мира. Minecraft menu и `enabled=false` по-прежнему отключают оформление.
- Проверено: компиляция/remap, ресурсные тесты, тесты профилей/FreeLook и статические макеты из тех же текстур. **Minecraft в этой среде не запускался**: применение новых Mixin, масштабирование реального GUI, прокрутка, двойной клик и взаимодействие с другими модами требуют проверки в игре.

### Проверка в игре

1. Оставьте в `mods` только `orbit-0.4.3-ui-fix.jar` (старый Orbit уберите из `mods`).
2. Проверьте главное меню, Profiles, поиск/выбор мира и список серверов: мышь, Tab/Enter, прокрутку, двойной клик и кнопки действий.
3. Измените размер окна и GUI scale. Особенно проверьте небольшой размер окна: кнопки Profiles/Minecraft menu не должны перекрывать главное меню.
4. Войдите в тестовый мир и выйдите обратно: оформление должно возвращаться, а игровой интерфейс оставаться стандартным.

## 0.4.1-profiles — предварительная панель Profiles

- Кнопка Profiles находится справа снизу в главном меню Orbit. Открывает стеклянную панель в стиле меню, с акцентной кнопкой выбора.
- Offline: добавить, выбрать, переименовать и удалить до 20 ников (3–16 латинских букв, цифр и подчёркиваний). Стрелки переключают записи. Выбор сохраняется, но **применяется только после перезапуска Minecraft через лаунчер**: так сервисы идентичности инициализируются с нужным профилем.
- Launcher account возвращает исходную сессию, которую лаунчер передаст при следующем запуске. Это не менеджер нескольких Microsoft-аккаунтов.
- Профили без регистрации работают в одиночной игре и на серверах без проверки аккаунтов; на лицензированных серверах вход с ними не обещается. Другой ник меняет offline UUID и может привести к другому инвентарю/данным игрока в существующих мирах и на серверах. Перед проверкой сделайте резервную копию мира.
- Вход Ely.by и самостоятельное добавление Microsoft-аккаунтов **пока не реализованы**. Пароли и токены мод не сохраняет. Файл `config/orbit/profiles.properties` содержит только имена и выбор; при ошибке чтения он не перезаписывается, используется аккаунт лаунчера.
- Эта версия — предварительная: сборка и тесты хранилища не заменяют запуск Minecraft. Проверь выбор, перезапуск, возврат к лаунчеру, Tab/Enter и разные GUI scale в отдельном тестовом мире без других модов.

- Новый оригинальный фон: слои фиолетовых облаков по мотивам присланного примера, без чужого брендинга. Фон статичный.
- Скруглённые почти прозрачные кнопки с тонкой светлой рамкой и плавной подсветкой при наведении/фокусе клавиатуры.

## FreeLook — сохранён из версии 0.2.0

**Написаны FreeLook и новое главное меню. Полный клиент из плана ещё не готов.**
Согласованные требования: [docs/PLAN.md](docs/PLAN.md).

### Что делает новая реализация

- В виде **от третьего лица со спины** (первое нажатие F5 из первого лица) удерживай **левый Alt**, чтобы вращать камеру, не меняя направление взгляда/движения персонажа мышью.
- При отпускании Alt камера плавно возвращается за спину. Во время возврата обычное управление мышью снова работает.
- Камерные углы изменяются до стандартного расчёта положения камеры: ванильное ограничение камеры стенами остаётся в цепочке.
- В первом лице, во фронтальном F5, в меню, при потере фокуса, смерти или смене мира FreeLook сбрасывается. После сброса сначала отпусти клавишу и зажми заново.
- Клавиша переназначается в **Настройки → Управление → Назначение клавиш → Разное → Orbit: свободный обзор (удерживать)**. Minecraft сохраняет её в своих настройках.
- В версии 0.3.1 используется общая строка инициализации меню и FreeLook, указанная выше.

Это описание реализации, а не подтверждение теста в Minecraft. Компиляция и применение Mixin требуют проверки нового запуска Actions и игры.

### Сохранение настроек

При первом запуске создаётся `config/orbit/freelook.properties`:

```properties
enabled=true
returnSpeed=12.0
```

`returnSpeed` — скорость возврата в диапазоне **1–40**: больше = быстрее. Меняй при закрытой игре; файл читается при запуске. Неверный файл не перезаписывается: функция отключается, ошибка записывается в журнал. Собственного экрана настроек пока нет.

**Ещё НЕ реализованы:** ClickGUI, ручные темы интерфейса, голова/баланс в меню, профили Singleplayer/Multiplayer, Baritone, Freecam, ESP и остальные модули из плана.

## Сборка и установка

1. Открой **Actions → Orbit - Fabric build** и последний запуск актуального коммита.
2. Он выполняет отдельные тесты состояния/конфига камеры, компиляцию/remap и проверку классов/метаданных JAR. Эти проверки не запускают Minecraft.
3. При зелёном статусе скачай из **Artifacts** `orbit-1.21.11-0.4.3-ui-fix` и распакуй ZIP.
4. Закрой игру. Перемести старый Orbit JAR в запасную папку **вне `mods`** и положи `orbit-0.4.3-ui-fix.jar` в `mods`. Одновременно оставляй только одну версию Orbit.
5. Используй Minecraft **1.21.11**, Fabric Loader **0.20.1+**, Fabric API **0.141.6+1.21.11** и Java 21, как в успешном тесте основы.
6. Первый тест проведи в отдельном одиночном мире, сначала без дополнительных модов. Затем отдельно проверь с Sodium подходящей версии.

Если запуск Actions красный, пришли блок `What went wrong` или ошибки `compileClientJava`. При краше Minecraft — ошибку `Mixin`/`Caused by` из `logs/latest.log` или краш-репорт, скрыв личные данные.

Если автоматического запуска нет: **Run workflow → main → Run workflow**. **Re-run** старого запуска повторяет старый коммит, а не новые исходники.

## Чек-лист в игре

- Игра запускается, в логе новая версия Orbit, в управлении есть назначение FreeLook.
- F5 со спины → удерживать W, затем Alt → двигать мышью влево/вправо: путь персонажа не должен поворачиваться за камерой.
- То же со спринтом и прыжками; вверх/вниз без переворота камеры.
- Отпустить Alt: возврат за спину без поворота персонажа; снова работает обычная мышь.
- Быстро повторно зажать Alt во время возврата: камера не должна резко перескакивать.
- Esc, Alt-Tab, смена F5, смерть/возрождение, выход и повторный вход: никаких застрявших углов или ввода; для повторной активации отпустить Alt и зажать снова.
- Проверить переназначение клавиши и загрузку изменённого `returnSpeed` после перезапуска.
- Сравнить поведение при низком и высоком FPS; не атаковать/строить, ориентируясь по свободной камере: направление взаимодействий остаётся направлением персонажа.

## Что проверено

- Основа 0.1.0-bootstrap ранее собрана и запущена пользователем с Fabric 1.21.11 / Java 21; в журнале есть инициализация и вход в одиночный мир.
- Для новой реализации есть независимые Java-тесты вращения, ограничений pitch, плавного возврата, повторного удержания, независимости от частоты кадров и сохранности конфигов.
- Тесты запускаются командой `bash scripts/test-freelook.sh` без Minecraft-зависимостей. Они НЕ проверяют применение миксинов, потерю фокуса в настоящем окне и визуальный результат.
- Состояние новой сборки Actions и тест в игре следует подтверждать отдельно; наличие исходников не означает, что проверка уже прошла.

## Технические зависимости

Версии основы взяты из официального `FabricMC/fabric-example-mod`, ветка `1.21.11`, commit `8272aadc8605a4661685465c22f80aab21c7b969`:

- Minecraft 1.21.11; Fabric Loader 0.20.1; Fabric API 0.141.6+1.21.11.
- Loom 1.19-SNAPSHOT; Gradle 9.8.2.
- **JDK 25 для Gradle/Loom**, целевой байткод собственного мода **Java 21**.
- MixinExtras используется из Fabric Loader; отдельный мод для него не требуется. Клиентские миксины объявлены с `JAVA_21` и `defaultRequire: 1`: несовпадение точки внедрения не должно молча скрываться.

Loom остаётся upstream SNAPSHOT, поэтому полностью воспроизводимая сборка пока не гарантирована. Сетевые зависимости доступны GitHub Actions; локальная среда разработки без сети не может собрать весь Minecraft-мод.

Локальная сборка при установленном Gradle 9.8.2, JDK 25 и Python 3: `gradle --no-daemon build`. Gradle автоматически восстанавливает подготовленную PNG-иконку из текстового ресурса скриптом `tools/generate_icon.py`; внешние Python-пакеты не требуются. Если Python вызывается командой `python`, добавь `-PpythonExecutable=python`. Gradle Wrapper пока не добавлен.

В репозиторий не включаются файлы Minecraft, секреты, токены или сторонний Baritone JAR. Baritone не подключён. Google Диск на этом этапе не изменяется.

## Замена логотипа в 0.3.1

Использована присланная картинка: чёрные поля обрезаны, чёрный фон заменён прозрачностью, белая форма и обе звезды сохранены. Подготовленный логотип 512×512 хранится как `tools/assets/orbit-logo.png.b64` и восстанавливается при сборке без внешних Python-пакетов. Это логотип главного меню и иконка мода, не аватар аккаунта и не значок отдельного лаунчера. Синяя тема, кнопки и FreeLook не менялись. Новая сборка и запуск требуют проверки Actions и Minecraft.

Новые ресурсы `clouds.png` генерируются Python-скриптом из исходного дизайна. Для новой сборки Actions проверяет наличие фонового PNG и обоих новых клиентских mixin-классов. Google Диск не изменялся.
