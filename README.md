# Orbit client — Fabric 1.21.11

**Этап: минимальная основа для проверки сборки. Это ещё не готовый чит-клиент.**

Согласованные требования: [docs/PLAN.md](docs/PLAN.md).

## Что есть в коде сейчас

- Клиентский Fabric-entrypoint, который пишет в журнал:
  `[Orbit] Bootstrap initialized. Gameplay modules are NOT implemented yet.`
- Конфигурация Gradle/Loom и мод-метаданные для Minecraft **1.21.11**.
- GitHub Actions: проверка опубликованных версий зависимостей, компиляция/remap, проверка содержимого JAR, загрузка артефакта.

**Пока не реализованы:** FreeLook, ClickGUI, темы/профили, HUD, Baritone и остальные игровые модули. Их названия в плане — требования, не готовые переключатели.

## Проверить сборку в GitHub

1. Открой вкладку **Actions → Orbit - Fabric build**.
2. Открой последний запуск. Зелёный статус означает успешное выполнение проверки зависимостей и сборки, но не тест в игре.
3. Внизу успешного запуска, в **Artifacts**, скачай `orbit-1.21.11-bootstrap` и распакуй ZIP.
4. Если запуск красный: открой шаг с ошибкой, скопируй текст ошибки и последние 40–60 строк. Не присылай токены.
5. Если автоматического запуска нет: **Run workflow → main → Run workflow**. Если Actions отключены, сначала включи их для этого репозитория, не отключая политики организации.

## Первый запуск в игре — только после успешной сборки

1. Установи профиль Minecraft Java **1.21.11** с совместимым Fabric Loader (текущая основа требует **0.20.1 или новее**).
2. Положи собранный `orbit-0.1.0-bootstrap.jar` и Fabric API для **1.21.11** в `mods` отдельного тестового профиля. Текущая зависимость API: **0.141.6+1.21.11**.
3. Запусти Minecraft с Java 21 или новее, совместимой с этой версией игры, и открой тестовый одиночный мир.
4. В `logs/latest.log` найди `Bootstrap initialized`. Никакого собственного меню или игровых функций на этом этапе быть не должно.
5. При сбое пришли соответствующую ошибку из журнала/краш-репорта; предварительно убери личные данные и адреса серверов.

## Источник версий

Версии взяты из официального `FabricMC/fabric-example-mod`, ветка `1.21.11`, commit `8272aadc8605a4661685465c22f80aab21c7b969`:

- Minecraft 1.21.11
- Fabric Loader 0.20.1
- Fabric API 0.141.6+1.21.11
- Loom 1.19-SNAPSHOT
- Gradle 9.8.2
- Java target 21

Loom в этом шаблоне — SNAPSHOT, поэтому сборка пока не полностью воспроизводима. Наличие версии в шаблоне не заменяет успешную сборку; стабильную версию Loom следует зафиксировать после проверки совместимости.

В репозиторий не включаются игровые файлы Minecraft, секреты, токены или сторонний Baritone JAR. Baritone пока не подключён и не проверен.

## Локальная сборка

При установленном Gradle 9.8.2 и Java 21: `gradle --no-daemon build`.
Gradle Wrapper пока не добавлен; команды `./gradlew` и `gradlew.bat` на этом этапе отсутствуют.
